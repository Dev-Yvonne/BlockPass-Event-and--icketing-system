# Two-minute demo script

A captioned recording is in [BlockPass-Round-1-Demo.mp4](BlockPass-Round-1-Demo.mp4). It has no
voiceover and was recorded on a local build. Use this script to re-record on the deployed app.

| Time | Show | Say |
| --- | --- | --- |
| 0:00 | Events page | "BlockPass helps people discover and host events across Africa, with tickets that can't be copied." |
| 0:12 | Nairobi Cultural Nights, gallery and schedule | "Each event has a full profile: photos, highlights, the schedule and venue guidance." |
| 0:30 | Checkout form | "An attendee needs a name, an email and a quantity. There's no wallet to set up." |
| 0:40 | Pay with options | "They can pay in local currency, which is a sandbox today, or with a stablecoin on Stellar." |
| 0:50 | Pay and wait | "Payment and ticket issuance happen in one atomic Stellar transaction." |
| 1:00 | Confirmation, StellarExpert | "Here are the unique tickets and the transaction hash, and this is the same record on a public explorer." |
| 1:20 | Organizer overview, feedback | "Organizers track sales, attendees and reviews in their own workspace." |
| 1:40 | Admin overview, users | "Administrators see the whole platform. Attendees can't reach any of this, in the app or through the API." |
| 1:55 | Events page | "Next comes the mobile ticket and the gate scanner." |

Before recording, buy one ticket to warm up the app, and use a new email address so wallet creation
is part of the demo.
